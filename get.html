Other platforms ↓

Every release ships its checksums — compare your download against SHA256SUMS.txt before installing. Each release also carries a signed sov-manifest.json — the file the app itself verifies (Ed25519, against the trust key built into it) before it will self-update.

On a Mac, why the warning? The Mac builds are not signed by Apple. Signing means buying an identity from Apple and renewing it every year, and SOV has no company to put on it — that is the point of the project, not an oversight. So macOS treats the app as coming from an unidentified developer. Unpack it, right-click the app and choose Open; if macOS still refuses, allow it once in System Settings → Privacy & Security. If you prefer the Terminal: xattr -d com.apple.quarantine "SOV Node.app". Check the download against SHA256SUMS.txt first — that tells you the file is the one the network published, which is the thing worth knowing.

GitHub down or blocked where you are? The same v1.2.24 files are also seeded over BitTorrent by the network’s own nodes — no account, no company, nothing to suspend. Use the .torrent file if your client finds no peers: it carries a web seed, so the download completes from either source, and the checksums above still apply.

Run a node on a server (Linux)

For a machine with no desktop — a VPS or a home server. This is the node software itself, version 1.4.88-plain, the exact package every node on the network runs. Get it whichever way suits you; the checksum is the same for all of them.

Download sov-relay.snap
In a terminal: curl -LO https://github.com/sov-network/relay-releases/releases/latest/download/sov-relay.snap
Checksum: sov-relay.snap.sha256 (SHA-256 91d58f27a67700b1d285247f469394263f0ba73bf4ab8d60dccfdd2abd86385f)
By torrent: sov-relay.snap.torrent · magnet link
On IPFS: ipfs get bafybeigig4ulbnwukghlnfzays7zwyj5vpv76c2vanpapl7z7ydr75bgty -o sov-relay.snap (gateway)
