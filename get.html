Every release ships its checksums — compare your download against SHA256SUMS.txt before installing. Each release also carries a signed sov-manifest.json — the file the app itself verifies (Ed25519, against the trust key built into it) before it will self-update.

GitHub down or blocked where you are? The same v1.2.1 files are also seeded over BitTorrent by the network’s own nodes — no account, no company, nothing to suspend. Use the .torrent file if your client finds no peers: it carries a web seed, so the download completes from either source, and the checksums above still apply.
