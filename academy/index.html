SOV Network — Academy

The SOV Academy is the network's civic-education library: what SOV is, how to use it,
the protocols that make it work, and how to run a node yourself. It ships inside the SOV
app and is mirrored here as a plain web page so anyone can read it — no install required.

Where the network stands — September 2026. The SOV Network has been live since 25 August 2026. The current app is v1.2.1, released for Android, Windows, macOS and Linux. On all three desktop systems the app is also a full node: install it, turn the node on, and you are serving the network. The separate headless package, for a server with no desktop, is not yet distributed — see Run a Node, section 6. Guidance here is updated as those change.

About this content

  • It mirrors the Academy inside the SOV app, so the guidance is the same on the site and on your device.
  • It contains civic education and operator instructions only — no private keys, no
    network internals that would weaken the protocol.
  • SOV is an open protocol: self-contained nodes, no central operator list, no single
    switch to flip. Running a node makes the network stronger and more independent.
